# 🚀 Missione 00: Il tuo primo Push!

Benvenuto nel tuo primo vero progetto GitHub! In questo esercizio imparerai il flusso di lavoro che useremo per tutto l'anno per scaricare i compiti, scriverli su CLion e consegnarli in modo sicuro.

## Obiettivo
Creare una copia personale e PRIVATA di questo progetto, scaricarla sul tuo computer, modificare il codice in C e "consegnarlo" (Push) su GitHub.

---

### Fase 1: Crea il TUO repository (Fallo su GitHub)
Non puoi modificare questo file perché è il Template del prof. Devi creare la tua copia:
1. Clicca sul pulsante verde in alto a destra: **Use this template** e poi **Create a new repository**.
2. ⚠️ **ATTENZIONE - Owner:** Nel menu a tendina "Owner", NON lasciare il tuo nome utente, ma seleziona l'Organizzazione della classe (es. *Informatica-3A-2627*).
3. **Repository name:** Inserisci esattamente `00-Setup-TuoCognome` (es. `00-Setup-Rossi`).
4. ⚠️ **ATTENZIONE - Visibilità:** Seleziona assolutamente **Private**. (Se metti Public, i tuoi compagni potranno copiare il tuo codice e prenderete un brutto voto in due!).
5. Clicca su **Create repository**.

Ora sei nel TUO repository privato. Copia l'URL che trovi nella barra degli indirizzi del browser.

---

### Fase 2: Porta il codice su CLion (Clone)
1. Apri **CLion**.
2. Nella schermata di benvenuto, clicca su **Get from VCS** (o vai su `File -> New -> Project from Version Control...`).
3. Nella casella "URL", **incolla il link** del tuo repository.
4. Clicca su **Clone**.

---

### Fase 3: Scrivi il codice in C
1. Nel pannello di sinistra (Project), apri il file `main.c`.
2. Scrivi un programma che stampi a schermo questa esatta frase (sostituendo il tuo nome):
   > "Ciao GitHub! Sono [Tuo Nome] e sono pronto per iniziare a programmare in C."
3. Testa il programma premendo il tasto verde ▶️ (Play).

---

### Fase 4: Consegna il compito (Commit & Push)
Il codice funziona sul tuo PC, ora "consegnalo" al prof:
1. Premi **`Ctrl + K`** (Windows) o **`Cmd + K`** (Mac).
2. Nello spazio "Commit Message" scrivi: *"Completato setup e aggiunto il saluto"*.
3. In basso, clicca sulla freccina di fianco a "Commit" e scegli **Commit and Push...**
4. Clicca sul pulsante azzurro **Push**.

🎉 **Fatto!** Torna sulla pagina del tuo repository su GitHub e ricarica: se vedi il tuo nuovo codice, hai consegnato con successo!
